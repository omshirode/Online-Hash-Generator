# 🔐 Online Hash Generator

An easy-to-use web application that allows users to generate cryptographic hash values for any input text using popular algorithms like MD5, SHA-1, SHA-256, and more.

## 🚀 Features

- Generate hashes using various algorithms:
  - MD5
  - SHA-1
  - SHA-256
  - SHA-384
  - SHA-512
- Clean, user-friendly interface
- Real-time hash generation
- Copy-to-clipboard functionality
- Lightweight and fast

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript (or React/Vue if applicable)
- **Hashing Library**: [CryptoJS](https://github.com/brix/crypto-js) / native Web Crypto API
- **Hosting**: GitHub Pages / Netlify / Vercel / Your preferred platform
